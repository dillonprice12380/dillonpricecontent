# Dillon Price Content Portfolio

A personal portfolio site for **Dillon Price** — Content Writer & Strategist with 8+ years of experience in SEO-driven content and topical authority.

## Live Site

> This repository hosts the source code for [dillonpricecontent.com](https://dillonpricecontent.com)

## About

Dillon specializes in long-form, search-optimized articles across industries including legal services, higher education, career development, and remote work. His bylined work appears on **Monster.com**, **University of Phoenix**, and **EnRoute Jobs**.

## Project Structure

```
dillonpricecontent/
├── index.html      # Main portfolio page (hero + article list)
├── styles.css      # Dark theme styles with teal accents
└── script.js       # Filter, search, and pagination logic
```

## Features

- **Hero section** with bio and contact links (email & LinkedIn)
- **Portfolio article list** with 40+ published articles
- **Filter by publisher** (University of Phoenix, Monster.com, EnRoute Jobs)
- **Live search** by article title
- **Pagination** (5 articles per page)
- **Responsive design** for mobile and desktop

## Tech Stack

Plain HTML, CSS, and vanilla JavaScript — no build tools or dependencies required.

## Getting Started

1. Clone the repo:
   ```
   git clone https://github.com/dillonprice12380/dillonpricecontent.git
   ```
2. Open `index.html` in your browser — or deploy to GitHub Pages / any static host.
